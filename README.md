# Modbus TCP Communication using Python and QModMaster

## Overview

This project demonstrates basic Modbus TCP communication using Python
and QModMaster.

A simulated Modbus TCP server is created using PyModbus, and QModMaster
is used as the Modbus client to read holding registers.

## Technologies Used

- Python
- PyModbus
- Modbus TCP
- QModMaster
- TCP/IP

## Function Code

Function Code 03 - Read Holding Registers

## Result

QModMaster successfully reads the holding registers
from the Python Modbus TCP server.
